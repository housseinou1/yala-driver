Suppression de Compte - Yala Driver

Demander la suppression de votre compte

Si vous souhaitez supprimer votre compte Yala Driver et toutes les données associées, suivez les étapes ci-dessous :

Comment supprimer votre compte :

  1. Envoyez un e-mail à sakhohousseinou@gmail.com
  2. Indiquez comme objet : "Demande de suppression de compte Yala Driver"
  3. Incluez dans le message :
    • Votre nom complet
    • L'adresse e-mail associée à votre compte
    • Votre numéro de téléphone
  4. Votre compte sera supprimé dans un délai de 7 jours ouvrables
Attention : La suppression de votre compte est irréversible. Les données suivantes seront définitivement supprimées :
  • Informations personnelles (nom, e-mail, téléphone)
  • Photo de profil
  • Documents d'identité
  • Historique des courses
  • Messages

Données conservées après suppression

Conformément à nos obligations légales, certaines données financières (historique des transactions) peuvent être conservées pendant une durée maximale de 12 mois après la suppression du compte.
