Politique de Confidentialité - Yala Driver

Dernière mise à jour : 2 juin 2026

1. Introduction

Yala Technologies ("nous", "notre") exploite l'application Yala Driver. Cette politique de confidentialité décrit comment nous collectons, utilisons et protégeons vos informations personnelles.

2. Données collectées

Nous collectons les données suivantes :

  • Informations personnelles : nom, prénom, adresse e-mail, numéro de téléphone
  • Documents d'identité : pièce d'identité nationale, permis de conduire
  • Données de localisation : position GPS exacte en temps réel pendant l'utilisation de l'application
  • Photos : photo de profil, photos des documents
  • Messages : communications entre chauffeurs et passagers

3. Utilisation des données

Vos données sont utilisées pour :

  • Fournir le service de transport (mise en relation chauffeur-passager)
  • Afficher votre position aux passagers pendant une course
  • Vérifier votre identité et vos documents
  • Communiquer avec vous concernant les courses
  • Assurer la sécurité des utilisateurs

4. Partage des données

Nous ne vendons pas vos données personnelles. Votre position est partagée avec les passagers uniquement pendant une course active.

5. Sécurité des données

Toutes les données sont transmises via une connexion sécurisée (HTTPS). Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos informations.

6. Conservation des données

Vos données sont conservées tant que votre compte est actif. Vous pouvez demander la suppression de votre compte et de vos données à tout moment.

7. Vos droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Corriger vos données
  • Demander la suppression de votre compte
